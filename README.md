# Lotus & Rice Asian Kitchen Website

## Live Demo
https://willowy-faloodeh-da5229.netlify.app/


## Overview
This is a multi-page restaurant website designed to showcase a modern Asian fusion kitchen. 
The goal of this project was to create a clean, responsive, and user-friendly experience that 
simulates a real restaurant website.
## My Role
I designed and developed the entire website, including UI layout, user interaction, and frontend logic.
## Features
- Multi-page layout (Home, Menu, About, Order, Contact)
- Shopping cart system using localStorage
- Fake login system (localStorage-based authentication)
- Order history tracking for users
- Contact form with confirmation message
- Embedded Google Maps for location
- Responsive layout and improved UI alignment


## Tech Stack
- HTML
- CSS
- JavaScript
- Netlify (deployment)
